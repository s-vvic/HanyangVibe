# 4. 비기능 요구사항

## 4.2 보안 요구사항

| 요구사항 ID | 요구사항 내용                                | 우선 순위 |
| :---------- | :------------------------------------------- | :-------- |
| NF-S-001    | 모든 통신 구간 WireGuard 기반 암호화 적용    | 필수      |
| NF-S-002    | 사용자 비밀번호 해시 저장 (bcrypt 이상)      | 필수      |
| NF-S-003    | JWT 기반 인증 토큰 적용                      | 필수      |
| NF-S-004    | 프라이버시 존 영역 마스킹은 보드 단에서 처리 | 필수      |
| NF-S-005    | 이상 접근 감지 시 알림 발송                  | 선택      |
