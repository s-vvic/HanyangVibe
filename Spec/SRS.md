# 1. 문서 개요

## 1.1 목적

본 문서는 Paper Traiding with Toss(이하 "트레이딩")의 기능적, 비기능적 요구사항을 정의함
API-Server, CSV-DB, paper-trading-engine, client로 구성된 4개 부체계의 기능사항을 각각 기술함

## 1.2 적용 범위

- 주체계: 트레이딩
- 부체계: API-Server, CSV-DB, paper-trading-engine, client

## 1.3 용어

| 용어          | 정의                                                                                  |
| ------------- | ------------------------------------------------------------------------------------- |
| 가상 자금     | 실제 자산이 아닌 서버측에서 임의로 설정한 자산                                        |
| 토스 API      | 토스에서 제공하는 토스증권 open api. '시세 조회 / 주문 연동 / 계좌 및 종목' 기능 지원 |
| API 호출 제한 | 시세 초당 10회, 주문 초당 6회 등 엔드포인트별 제한 적용                               |
| 우선 순위     | 최우선, 우선, 보통, 후순, 보류 순으로 우선 순위 책정                                  |
