# 1. 문서 개요

## 1.1 목적

본 문서는 Paper Traiding with Toss(이하 "트레이딩")의 기능적, 비기능적 요구사항을 정의함
API-Server, CSV-treat, paper-trading-engine, client로 구성된 4개 부체계의 기능사항을 각각 기술함

## 1.2 적용 범위

- 주체계: 트레이딩
- 부체계: API-Server, CSV-treat, paper-trading-engine, client

## 1.3 용어

| 용어      | 정의                                           |
| --------- | ---------------------------------------------- |
| 가상 자금 | 실제 자산이 아닌 서버측에서 임의로 설정한 자산 |
| 주문      | 매도/매수 요청                                 |
